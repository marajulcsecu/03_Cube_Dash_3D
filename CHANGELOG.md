# Changelog

All notable changes to the **Cube Dash 3D** project will be documented in this file.

## [1.0.0] - 2026-07-24
### Added
- Completed full production release of **Cube Dash 3D** for MegaGameBox Offline Arcade.
- Implemented `GameBridgeAdapter` with `onGameStart`, `onGameEnd`, `onQuit`, and `window.setAudioMuted` bridge contract bindings.
- Implemented versioned namespaced `StorageManager` with fallback handling and corruption protection.
- Optimized Three.js WebGL renderer lifecycle, object pooling, and responsive aspect-aware portrait camera scaling.
- Comprehensive automated unit test suite with 55 passing tests across 15 test suites.
